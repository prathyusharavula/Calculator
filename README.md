JavaScript Calculator
Developed a responsive calculator application using HTML, CSS, and JavaScript. Implemented core arithmetic operations including addition, subtraction, multiplication, and division with an intuitive user interface and real-time calculations.

Features :
Perform basic arithmetic operations (+, −, ×, ÷)
User-friendly and interactive interface
Real-time calculation display
Error handling for invalid inputs
Responsive design for desktop, tablet, and mobile devices

Technologies Used :
HTML5
CSS3
JavaScript

Key Learning Outcomes:
JavaScript Event Handling
DOM Manipulation
Arithmetic Logic Implementation
Responsive Web Design
User Interface Development

Project Description :
Built a functional calculator using JavaScript, implementing arithmetic operations and interactive button-based input. Designed a responsive layout to ensure seamless usability across various screen sizes while strengthening front-end development and DOM manipulation skills.
